# Лабораторная работа №5. Вариант 8

Тема: наследование, полиморфизм. Генерация карты с помощью шума Перлина.

Пользователь вводит ширину и высоту карты. Программа рассчитывает двумерный шум Перлина и выводит в консоль ландшафт: море, берег, равнину, лес, пустыню и горы. Никаких сторонних библиотек не требуется.

## Сборка

В папке проекта выполнить:

```bash
g++ -std=c++17 main.cpp perlin_noise.cpp map_generator.cpp -o lab5
```

Запуск в Linux:

```bash
./lab5
```

Запуск в Windows (MinGW):

```powershell
.\lab5.exe
```

## Классы

- `Noise` — абстрактный базовый класс, задающий интерфейс шума.
- `PerlinNoise` — наследник `Noise`, реализующий градиентный шум Перлина.
- `MapGenerator` — создаёт карту, вызывая метод через ссылку на базовый класс `Noise`.

Ссылка на `Noise` в `MapGenerator` используется для демонстрации полиморфизма. Передача генератора шума через конструктор соответствует идее паттерна «Стратегия».

UML-диаграмма находится в `classes.drawio`.
